# @egoist/solid-base-utils

Framework-agnostic DOM helpers and small SolidJS 2 primitives used by
[`@egoist/solid-base`](https://www.npmjs.com/package/@egoist/solid-base).

This package is an implementation detail of Solid Base and its API may change between minor
versions. See https://base.egoist.dev for the component library.
